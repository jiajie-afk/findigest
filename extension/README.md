# FinDigest 浏览器扩展（持仓导入）

必须先在浏览器里登录**网页交易账号**，才能读持仓。不采集、不存储券商账号密码。

行情软件（同花顺 PC、东财终端）读不到 —— 要用网页：

- 东方财富：https://jywg.18.cn/Login （登录后「查询 → 资金股份」）
- 同花顺：https://eq.10jqka.com.cn/

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions` 或 `edge://extensions`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本仓库的 `extension/` 目录
4. 固定扩展图标到工具栏

## 使用

1. 点扩展里的「打开东财登录」或「打开同花顺登录」
2. 用**交易账号**登录，打开持仓页
3. 点「读取本页持仓」→「发送到 FinDigest」
4. 在 FinDigest 校对表勾选后确认导入

读不到时：复制网页表格，在 FinDigest「粘贴表格」导入。
