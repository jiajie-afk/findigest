# FinDigest Douyin 2.0 — Design

**Concept:** 电子榨菜 vs 仓位含义。黑底冲击字卡砸脸，产品界面作「真相证据」。

## Palette
- bg: `#0a0a0a`
- ink: `#f5f0e6`
- accent gold: `#c5a059` (Museum)
- danger/punch: `#ff4d4d`
- mute: `#8a8578`

## Typography
- Display: `"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`
- Huge hook: 72–96px bold, tight leading
- Subtitle bars: 28–36px

## Layout
- 1080×1920 safe margins 64px
- Focal: center smash text first 2s
- UI shots: full-bleed with dark vignette + caption bar bottom
- Compliance: 22px bottom-left persistent

## Motion
- Smash in (scale 1.15→1 + opacity) for 加/减/装死
- Hard cuts between scenes; no soft dissolves
- UI panels slide up 24px / fade
